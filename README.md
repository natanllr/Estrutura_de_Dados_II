# 📚 Estrutura de Dados II

Após concluir a disciplina de **Estrutura de Dados I**, darei continuidade aos estudos na disciplina de **Estrutura de Dados II**, aprofundando os conhecimentos relacionados à organização, manipulação e otimização de dados em programas e sistemas.

Durante a disciplina, serão abordados novos conceitos e estruturas, buscando compreender não apenas como implementá-los, mas também **quando e por que utilizá-los**, considerando aspectos como eficiência, desempenho e complexidade dos algoritmos.

## 💻 Projeto da Disciplina

Ao longo da disciplina, será desenvolvido um **projeto prático relacionado aos conteúdos estudados**, com o objetivo de aplicar na prática os conhecimentos adquiridos durante as aulas.

Neste repositório, apresentarei o projeto, sua implementação e os principais conceitos utilizados, permitindo acompanhar minha evolução durante a disciplina e visualizar como os conhecimentos de **Estrutura de Dados I e II** podem ser aplicados no desenvolvimento de soluções computacionais.

## 🎯 Objetivo

Este repositório tem como objetivo **documentar meu aprendizado em Estrutura de Dados II**, reunindo o projeto desenvolvido, implementações e conceitos estudados ao longo da disciplina.

> 🚀 **Da teoria à prática:** aplicando os conhecimentos de Estrutura de Dados para desenvolver soluções mais eficientes e organizadas.
